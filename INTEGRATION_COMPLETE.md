## 🎮 Как использовать

### Для демонстрации (быстро)
```bash
# Запуск демо-сервера
python qwen2vl_demo_server.py --host 0.0.0.0 --port 8888

# Тестирование
python test_integration.py
```

### Для продакшн (с реальной моделью)
```bash
# Установка MLX (только на macOS с Apple Silicon)
pip install mlx-vlm

# Запуск реального сервера
python qwen2vl_server.py --host 0.0.0.0 --port 8888

# В iOS приложении автоматически подключится
```

### В iOS приложении
```swift
// Автоматическая интеграция
let qwen2VLManager = Qwen2VLManager.shared
await qwen2VLManager.loadModel() // Подключится к серверу

// Анализ экрана
let task = UIAutomationTask(type: .findButton, target: "Login")
let result = await qwen2VLManager.analyzeScreenForUIAutomation(screenshot, task: task)
```
