## 🎯 Обзор проекта

iOS Eiros Agent - это комплексное приложение для iOS, интегрирующее:
- Локальную модель Qwen2VL через Python сервер
- OpenRouter API для доступа к внешним LLM
- Веб-автоматизацию и OCR системы
- Продвинутую систему анализа UI
